A token launch radar that ranks pre-token protocols from a sealed DefiLlama snapshot (758 protocols, 40-protocol watchlist) by an implied value model built on TVL, 7-day growth, time with no token, category, and chains. The dashboard is sortable and filterable, with a detail view for each protocol and concrete farm plans for every ranked row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
